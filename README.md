FitPredict AI

<a href="www.youtube.com"></a>

-> A full-stack machine learning web application that predicts fat loss based on a user's health and lifestyle data.

-> The goal of this project is to combine web development and machine learning into a single application that helps users understand how daily habits like calorie intake, exercise, sleep, and activity level can influence fat loss.

-> This project was built as a final-year engineering project to gain practical experience with full-stack development, REST APIs, databases, and machine learning.

Features :
User registration and login
Fat loss prediction using Machine Learning
Automatic BMI calculation
Weight loss estimation
Prediction confidence score
Dashboard with health analytics
Prediction history
Search and filter previous predictions
Export prediction history as CSV
Interactive charts and graphs
Responsive user interface
